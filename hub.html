接入新项目

只改一个文件，前端不用动

+ 预留插槽：data/projects.js 加一个对象即可

门户站不硬编码任何项目。卡片、@ 菜单、意图路由、健康探针、示例问题，全部从注册表读。 这就是「以后新做项目直接接入」的工程答案——不是留个空白 div，是留一条已经跑通的数据通路。

// data/projects.js 追加一项，刷新页面即生效
{
  id: "newproj", name: "新项目", tag: "领域 · 类型",
  accent: "#7c9cff", desc: "一句话说清它能干什么",
  url: "product-newproj.html",          // 点「进去用」跳这里
  tools: ["newproj.do_thing"],           // MCP 工具名，统一 project.verb_object
  skills: ["do_thing"],                    // A2A skill 名
  health: "http://127.0.0.1:8250/health", // 探针，2.5s 超时
  prompts: ["示例问题一"], demo: [ ... ]
}
